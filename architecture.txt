AUDIT STREAM
  every handled request -> stderr

MODERN RESPONSE RULES
  server identity -> response _meta
  cacheable results -> ttlMs: 0, cacheScope: private

FAILURE RULES
  bad protocol revision      -> JSON-RPC -32022
  malformed / missing meta   -> reject before downstream
  unknown / disallowed tool  -> reject before downstream
  downstream failure         -> tool result with isError: true

NON-GOALS
  no second approval system
  no Streamable HTTP / OAuth
  no prompts/resources/subscriptions
  no durable queue or audit store
